# Монтаж

## Что это
Лаборатория создания контента через ИИ.
Здесь пробуем, тестируем, запускаем.

## Инструменты
- **Remotion** — программный видеомонтаж
- **content-factory** — pipeline обработки видео
- **VASU-OS агенты** — автоматизация
- **MCP коннекторы** — интеграции
- **CapCut** — быстрый монтаж
- **Claude Code** — оркестрация
