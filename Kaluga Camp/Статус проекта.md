# Kaluga Camp — план по порядку

## 🎯 Конечная цель
Полноценная автоматизированная бизнес-система: сайт-лендинг, отметки на картах,
рабочие боты для записи, автоматизированные соцсети (VK, Instagram, Telegram)
и первые реальные отзывы от гостей после заезда.

## 📋 Последовательность шагов

### 1. Отметки на картах (быстро, независимо, делать сразу)
- [ ] Яндекс.Карты — создать/проверить организацию
- [ ] Google Maps — создать/проверить организацию
- [ ] 2ГИС — создать/проверить организацию

### 2. Оффер и цена (фундамент для всего остального)
- [ ] Определить тарифы: женский ретрит / корпоратив / семья
- [ ] Прописать, что входит в стоимость (шатёр, баня, питание, активности)
- [ ] Зафиксировать даты первого пилотного заезда

### 3. Визуальный контент (нужен для сайта и соцсетей)
- [ ] Собрать/отснять фото и видео территории, шатров, бани, йога-студии
- [ ] Подготовить визуал для лендинга и соцсетей

### 4. Сайт-лендинг (с формой брони)
- [ ] Собрать структуру и контент лендинга (с учётом оффера из шага 2)
- [ ] Разработка/сборка сайта — с формой бронирования
- [ ] Публикация и тест

### 5. Соцсети (наполняются на основе готового сайта)
- [ ] VK — регулярный контент-план и публикации, ссылка на сайт
- [ ] Instagram — запуск и первые посты
- [ ] Telegram — запуск канала
- [ ] Автоматизация кросспостинга (Make/Zapier или API)

### 6. Бот для записи (дублирует форму брони с сайта)
- [ ] Определить платформу (Telegram-бот / VK-бот)
- [ ] Прописать сценарий записи (синхронно с формой на сайте)
- [ ] Тест и запуск

### 7. Первые гости и отзывы (не через воронку — вручную)
- [ ] Найти гостей на пилотный заезд через личные связи/знакомых
- [ ] Провести первый заезд/ретрит
- [ ] Собрать обратную связь
- [ ] Опубликовать первые отзывы на сайте и в соцсетях
